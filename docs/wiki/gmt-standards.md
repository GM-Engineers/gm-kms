# GM/T 标准（密码行业标准）

> 上次更新：2026-06-23

## 基本信息

| 字段 | 值 |
|------|------|
| **全称** | 密码行业标准（国密标准） |
| **发布机构** | 国家密码管理局（OSCCA） |
| **标准号格式** | GM/T XXXX-XXXX |
| **适用范围** | 中国密码技术应用 |

## 概述

GM/T 标准是中国密码行业标准，由国家密码管理局发布实施。这些标准涵盖了国密算法、密码模块、密钥管理等方面，是在中国使用密码技术的合规依据。

## 主要标准分类

| 类别 | 标准编号 | 说明 |
|------|----------|------|
| **算法标准** | GM/T 0001-2012~0010-2012 | SM1-SM9 算法 |
| **算法使用** | GM/T 0002-2012~0006-2012 | SM2/SM3/SM4 使用 |
| **模块标准** | GM/T 0028-2014 | 密码模块安全检测要求 |
| **证书标准** | GM/T 0034-2014 | 基于 SM2 的数字证书格式 |
| **应用标准** | GM/T 0054-2018 | 密码应用基本要求 |

## KMS 相关的 GM/T 标准

### 1. GM/T 0002-2012（SM4 分组密码）

- 算法：128 位分组，32 轮 Feistel 结构
- 密钥：128 位
- 模式：ECB、CBC、CFB、OFB、CTR

### 2. GM/T 0004-2012（SM3 杂凑算法）

- 输出：256 位杂凑值
- 结构： Merkle-Damgård 结构
- 应用：数字签名、消息认证

### 3. GM/T 0003-2012（SM2 椭圆曲线公钥）

- 曲线：256 位曲线（类似 P-256）
- 三种模式：
  - SM2-1：签名
  - SM2-2：加密
  - SM2-3：密钥交换

### 4. GM/T 0028-2014（密码模块安全）

- 等效于 FIPS 140-2
- 安全等级：1-4 级
- 密码模块检测认证依据

### 5. GM/T 0054-2018（密码应用要求）

- 等保 2.0 密码应用对应标准
- 信息系统密码应用设计指南
- 密码应用安全性评估依据

## 等保密码应用要求（GM/T 0054）

| 要求级别 | 说明 |
|----------|------|
| **第一级** | 使用密码技术实现基本安全要求 |
| **第二级** | 使用合规密码产品，密钥管理规范 |
| **第三级** | 使用国密算法，密码模块认证，完整密钥管理 |
| **第四级** | 强制使用国密算法，HSM 保护，物理安全 |

## 在 KMS 中的实现

gm-kms 通过以下模块实现 GM/T 合规性：

| 模块 | 实现内容 |
|------|----------|
| `kms-core/algorithms.rs` | 算法抽象层，定义 Encryptor/Signer 等 trait |
| `kms-core/algorithms_impl.rs` | AES-256-GCM、SM4-GCM 具体实现 |
| `gm-sm9-rs`（外部依赖） | SM9 标识密码算法封装（默认 pure-rust 后端） |
| `kms-keystore/validation.rs` | 密钥材料验证 |

合规检查由各算法模块在初始化时自动执行。

## 认证体系

| 认证类型 | 说明 | 适用场景 |
|----------|------|----------|
| **产品型号认证** | 密码产品必须通过认证 | 所有密码产品 |
| **密码模块认证** | 模块安全等级认证 | 等效 FIPS 140 |
| **密评（密码应用评估）** | 信息系统密码应用评估 | 等保三级及以上 |
