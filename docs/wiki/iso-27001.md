# ISO 27001（信息安全管理体系） / ISO/IEC 27001:2022

> 上次更新：2026-06-29

| 字段 Field | 值 Value |
|------------|----------|
| **全称** | ISO/IEC 27001:2022 |
| **中文** | 信息安全管理体系要求 / Information Security Management System Requirements |
| **类型 Type** | 国际标准 / International Standard |
| **发布机构** | ISO/IEC |
| **适用范围** | 任何组织（不限行业和规模）/ Any organization (any industry/size) |


## 概述

ISO 27001 是信息安全管理体系（ISMS）的国际标准，定义了建立、实施、维护和持续改进信息安全管理体系的要求。它采用 PDCA（Plan-Do-Check-Act）循环，确保持续改进。

## 与 KMS 的关系

| ISO 27001 控制项 | KMS 实现 |
|-----------------|----------|
| **A.5 密码控制** | 密钥管理、加密算法 |
| **A.6 访问控制** | PBAC、RBAC、MFA |
| **A.8 资产管理** | 密钥分类、标签 |
| **A.10 通信安全** | TLS、传输加密 |
| **A.12 安全运营** | 审计日志、安全监控 |
| **A.18 合规性** | 合规报告、审计追溯 |

## ISO 27017（云服务安全） / ISO 27017 Cloud Services

ISO 27017 是专门针对云服务的信息安全控制指南，为云服务商和云客户提供了额外的控制措施。

| 控制项 Control | 说明 Description |
|--------------|----------------|
| **云服务商** / Cloud Provider | 云环境特定的安全控制 / Cloud-environment-specific security controls |
| **云客户** / Cloud Customer | 云使用中的安全责任划分 / Security responsibility split in cloud usage |


## KMS 在 ISO 27001 中的作用

```yaml
# ISO 27001 密码控制对应
cryptographic_controls:
  A.5.1: # 密钥管理
    requirement: "使用强加密算法，保护密钥"
    kms_implementation:
      - 算法: AES-256-GCM, SM2/SM3/SM4
      - 密钥存储: HSM
      - 密钥轮换: 自动轮换策略
      - 密钥备份: 安全备份

  A.5.2: # 保护传输中数据
    requirement: "使用加密协议保护传输"
    kms_implementation:
      - TLS 1.2/1.3
      - 证书管理自动化
```
