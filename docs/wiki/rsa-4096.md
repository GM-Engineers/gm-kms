# RSA-4096 非对称加密算法 / RSA-4096 Asymmetric Encryption Algorithm

> 上次更新：2026-06-29

## 基本信息 / Basic Information

| 字段 Field | 值 Value |
|------------|----------|
| **全称** | Rivest-Shamir-Adleman (RSA) |
| **类型 Type** | 非对称加密（公钥密码体系）/ Asymmetric cryptography |
| **密钥长度** | 4096 位（524 字节）/ 4096-bit (524 bytes) |
| **标准 Standard** | PKCS#1 v2.2 (RFC 8017) |
| **发布机构** | RSA Laboratories（现 RSA Security） |
| **算法公开性** | 公开 / Public |


## 算法概述

RSA 是最早的广泛使用的公钥密码系统，由 Ron Rivest、Adi Shamir 和 Leonard Adleman 于 1977 年在 MIT 设计。其安全性基于大整数分解的困难性。

### 关键参数

| 参数 | 值 |
|------|------|
| **模数长度** | 4096 位（512 字节） |
| **公钥指数 (e)** | 通常为 65537 |
| **私钥指数 (d)** | 由 p、q 派生 |
| **素数因子** | p, q（各约 2048 位） |
| **欧拉函数 φ(n)** | (p-1)(q-1) |

### 安全强度

| 密钥长度 | 约等价安全强度 | NIST 建议用途 |
|----------|----------------|---------------|
| 2048 位 | 112 bit | 长期密钥（2030+） |
| **4096 位** | **~140 bit** | 极高敏感数据 |
| 8192 位 | ~190 bit | 未来扩展 |

## 应用场景 / Use Cases

| 场景 Scenario | 说明 Description |
|--------------|----------------|
| **数字签名** / Digital Signature | RSA-PSS、RSA-PKCS#1 v1.5 |
| **密钥交换** / Key Exchange | RSA-OAEP、密钥封装 / RSA-OAEP, key encapsulation |
| **SSL/TLS 证书** / SSL/TLS Certs | 早期广泛使用，现多被 ECC 替代 / Widely used early, now often replaced by ECC |
| **PGP/GPG** | 邮件加密 / Email encryption |
| **Java Keystore / PKCS#12** | 密钥库格式 / Keystore format |


## 算法变体 / Algorithm Variants

| 变体 Variant | 说明 Description |
|-------------|----------------|
| **PKCS#1 v1.5** | 经典填充方案，存在 Bleichenbacher 攻击风险 / Classic padding, vulnerable to Bleichenbacher attack |
| **PKCS#1 v2.1 (RSA-OAEP)** | 更安全的填充，用于加密 / More secure padding, for encryption |
| **PKCS#1 v2.2 (RSA-PSS)** | 概率签名方案，用于签名 / Probabilistic signature, for signing |
| **RSA-KEM** | 密钥封装机制，更现代 / Key encapsulation mechanism, more modern |


## 与 ECC 对比 / ECC Comparison

| 对比项 Comparison | RSA-4096 | ECC P-384 |
|-----------------|-----------|-----------|
| 密钥长度 / Key Size | 4096 位 | 384 位 |
| 私钥大小 / PrivKey Size | ~512 字节 | ~48 字节 |
| 签名大小 / Sig Size | 512 字节 | 96 字节 |
| 计算成本 / Compute Cost | 高（慢）/ High (slow) | 低（快）/ Low (fast) |
| 适用场景 / Use Case | 兼容性优先 / Compatibility-first | 性能优先 / Performance-first |
