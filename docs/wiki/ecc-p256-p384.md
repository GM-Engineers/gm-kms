# ECC P-256 / P-384 椭圆曲线密码 / ECC P-256 / P-384 Elliptic Curve Cryptography

> 上次更新：2026-06-29

## 基本信息 / Basic Information

| 字段 Field | 值 Value |
|------------|----------|
| **全称** | Elliptic Curve Cryptography (Prime Field Curves) |
| **类型 Type** | 非对称加密（椭圆曲线密码）/ Asymmetric cryptography (ECC) |
| **标准 Standard** | FIPS 186-4, SEC 2, RFC 5480 |
| **发布机构** | NIST（美国国家标准与技术研究院）/ NIST |
| **算法公开性** | 公开 / Public |


## 曲线参数 / Curve Parameters

### P-256 (secp256r1)

| 参数 Parameter | 值 Value |
|--------------|----------|
| **曲线名称** | P-256 / secp256r1 / prime256v1 |
| **密钥长度** | 256 位 / 256-bit |
| **素数模 p** | 2^256 - 2^224 + 2^192 + 2^96 - 1 |
| **安全强度** | 128 位（与 AES-128 等价）/ 128-bit (equivalent to AES-128) |
| **签名长度** | 64 字节（512 位）/ 64 bytes |

### P-384 (secp384r1)

| 参数 Parameter | 值 Value |
|--------------|----------|
| **曲线名称** | P-384 / secp384r1 |
| **密钥长度** | 384 位 / 384-bit |
| **素数模 p** | 2^384 - 2^128 - 2^96 + 2^32 - 1 |
| **安全强度** | 192 位（与 AES-192 等价）/ 192-bit (equivalent to AES-192) |
| **签名长度** | 96 字节（768 位）/ 96 bytes |


## 算法概述

ECC 基于椭圆曲线离散对数问题的困难性。相比 RSA，在相同安全强度下密钥长度更短、运算更快。

### P-256 vs P-384 选择

| 场景 | 推荐曲线 |
|------|----------|
| 通用互联网应用 | P-256（性能和安全性平衡） |
| 政府/金融高安全 | P-384 |
| TLS/SSL 证书 | P-256 或 P-384 |
| 数字签名（ECDSA） | 两者均支持 |

## 应用场景 / Use Cases

| 场景 Scenario | 说明 Description |
|--------------|----------------|
| **ECDSA 签名** / ECDSA Signing | P-256 常用于 TLS 证书签名 / P-256 commonly used for TLS certificate signing |
| **ECDH 密钥交换** / ECDH KEX | TLS 1.3 中的默认密钥交换 / Default key exchange in TLS 1.3 |
| **Bitcoin / Ethereum** | secp256k1（非 NIST 曲线）/ secp256k1 (non-NIST curve) |
| **Apple Platform** | P-256（Secure Enclave 支持）/ P-256 (Secure Enclave supported) |
| **WebAuthn / FIDO2** | P-256 用于公钥凭证 / P-256 for public key credentials |


## 技术特点

1. **短密钥高安全**：256 位 ECC ≈ 3072 位 RSA 安全性
2. **计算效率高**：适合移动设备和嵌入式
3. **广泛支持**：主流平台、浏览器、硬件 token 均支持
